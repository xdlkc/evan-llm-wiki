# Generic LLM Wiki Rules for Claude Code

Follow `AGENTS.md` in this repository.

Additional requirements:

1. Treat the wiki as a maintained Markdown knowledge base.
2. Read source files directly from `raw/` and update `wiki/` directly.
3. Prefer editing existing concept or entity pages over creating duplicate pages.
4. Keep every claim traceable to source files.
5. Do not modify files under `raw/`.
6. If the source includes images or screenshots that matter, inspect them before writing.
7. Prefer one primary human-readable source in frontmatter, usually `README.md` when present.
